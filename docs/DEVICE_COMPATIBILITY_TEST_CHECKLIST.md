# 여러 기기 테스트 체크리스트

자동 검증은 실제 카메라 하드웨어 검증과 구분합니다. 배포 후 아래 항목을 각 기기에서 직접 확인합니다.

| 대상 | 확인할 브라우저 / 화면 |
| --- | --- |
| iPhone | Safari, 작은 화면과 노치가 있는 화면 |
| Android | Chrome, Samsung Internet |
| 폴더블 | 접은 화면 → 펼친 화면 → 접은 화면 |
| 태블릿 | 세로 → 가로 |
| PC | Chrome 또는 Edge, 내장·외장 카메라 |

- [ ] HTTPS 주소에서 열고 `카메라 시작`을 누를 때만 권한을 요청한다.
- [ ] 권한을 거부하면 안내가 나오고, 브라우저 설정에서 허용 후 다시 시작할 수 있다.
- [ ] 기본 후면 카메라 영상이 보이고 촬영 버튼에 접근할 수 있다.
- [ ] 여러 카메라가 노출되면 선택 목록이 보이며, 선택 후 이전 카메라가 해제된다.
- [ ] 수동 선택한 카메라가 사라지면 자동 선택으로 바꾸어 다시 시작할 수 있다.
- [ ] 작은 화면, 가로 화면, 큰 글씨 설정에서 가로 스크롤이나 버튼 잘림이 없다.
- [ ] 접기·펼치기와 회전 중 영상은 계속 재생되고, 가이드가 영상 안에 남는다.
- [ ] 촬영 결과의 가장자리·방향·글자 선명도를 확인한다. 정지사진은 기기에 따라 미리보기와 화각이 다를 수 있다.
- [ ] 촬영 후 이전 박스로 이동해 사진을 확인하고, 재촬영하면 최신 사진으로 바뀐다.
- [ ] 촬영 중 카메라 전환과 박스 이동이 잠겨 사진이 다른 박스에 기록되지 않는다.
- [ ] 다른 앱의 카메라 사용이나 기기 잠금으로 연결이 끊겨도 다시 시작할 수 있다.
- [ ] 뒤로 가기 후 돌아오면 카메라를 다시 시작할 수 있다.
- [ ] 새로고침 후 사진과 진행 상태가 복원된다.
- [ ] 사진 파일 공유가 지원되면 기기의 공유창이 열린다. 미지원이면 ZIP 저장 안내가 보인다.
- [ ] ZIP 저장 후 사진과 manifest의 크기·박스 번호·파일 경로가 맞는다.
- [ ] 다른 사람의 기기에서 같은 URL을 열어도 사진·진행 상태가 섞이지 않는다.
